## The fortune

> You will be replaced by a newer model soon. Relax: your replacement will be replaced too.

## How it works

`main.ts` writes that single fixed line to `/output/entry.txt`. No randomness,
no network, no external input: running it twice produces byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```
